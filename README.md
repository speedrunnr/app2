# New Age Tech Index v2.1

Live tiered equal-weight index tracking Indian new-age tech startups.

## Deploy to Streamlit Cloud

1. Fork this repo
2. Go to [share.streamlit.io](https://share.streamlit.io)
3. Click "New app"
4. Paste your repo URL and deploy

## Features
- Real-time data from Yahoo Finance
- Tiered equal-weight methodology (Large/Mid/Small)
- Interactive dashboard
- P/E, volatility, beta, gainers/losers
